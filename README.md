# OPD & Nurse Note Audit — โรงพยาบาลมหาราชนครเชียงใหม่

เว็บแอพพลิเคชันประเมินคุณภาพเวชระเบียนผู้ป่วยนอกและบันทึกทางการพยาบาล (Nurse Note) ที่รวมแบบประเมินทั้ง 3 เกณฑ์ (**OPD สปสช.**, **OPD HA IT**, **ห้องผ่าตัดเล็ก**) ไว้ในระบบเดียว

## ฟีเจอร์หลัก
- แยกโครงสร้าง **14 หน่วย / 36 ห้องตรวจ (OPD)** และจัดเก็บข้อมูลแยกตามหน่วยและห้องตรวจ
- รวมส่วน **Nurse Note** เป็นมาตรฐานกลางชุดเดียว ตัดข้อซ้ำซ้อนออกทั้งหมด
- วันที่ทำการประเมินแบบ **วัน/เดือน/ปี (พ.ศ.)**
- เชื่อมต่อ **Google Sheets** อัตโนมัติ (บันทึกเข้าชีตรวม `All_Audits` และแยกชีตอัตโนมัติตาม `หน่วย - ห้องตรวจ`)
- แดชบอร์ดกราฟและแผนภูมิแสดงร้อยละ (`%`) แยกตามหน่วย ห้องตรวจ เกณฑ์ และแนวโน้มรายวัน
- ส่งออกรายงานเป็น **PDF** และ **Excel (.xlsx)**
